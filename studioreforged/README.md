# Studio Reforged

Starter site for studioreforged.com — currently a "coming soon" / in-development landing page.

## Deploying on Netlify

1. Create a new site on Netlify and point it at this repository.
2. Set the **base directory** to `studioreforged`.
3. Publish directory: `.` (relative to base directory).
4. Deploy — the `netlify.toml` in this folder handles redirects for a single-page site.
