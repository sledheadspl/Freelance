# The Income Stability System

**$297 · Tier 3 of the RateTruth offer stack**

This is the top of the stack — for freelancers who've already bought the Rate Reality Kit, applied it, and want the full system instead of individual pieces. It does not get built until Tier 1 and Tier 2 have actual paying customers. Building a $297 product before anyone has paid $19 is the exact over-building mistake this whole offer stack is designed to avoid — see `DEMAND-ALCHEMY.md`.

## Planned outline (build after validation)

1. **The Value-Based Pricing Transition** — a full framework for moving an existing client base off hourly billing without a mass exodus, including how to sequence which clients to re-price first
2. **The Capacity & Pipeline Plan** — a simple weekly system for keeping 2-3 active leads in motion at all times, so income gaps get caught months ahead instead of the week the bank balance drops
3. **Rate-Raise Without Losing the Client, Expanded** — the scheduling rule from the Rate Reality Kit, expanded into scripts for every common pushback ("I can't afford that," "Can we phase it in," silence)
4. **Retainer Portfolio Design** — turning the single retainer script from the Systemization Pack into a target mix (e.g. 2 retainers + 1-2 project clients) sized to the freelancer's own income goal from the original calculator

## Validation trigger

Start building this once Tier 1 has sold at least 15-20 units *and* at least a few buyers have asked "is there anything more in-depth than this?" unprompted. That question, not a hunch, is the signal real demand exists for the $297 tier.
