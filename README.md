# RateTruth

A faceless, zero-budget offer stack for freelancers, built on top of one free tool.

**Free hook:** [`freelance-profit-calculator.html`](freelance-profit-calculator.html) — shows freelancers the gap between what they bill and what they actually keep.

**Paid stack:** [`offer-stack.html`](offer-stack.html) — three one-time-purchase tiers that fix the gap the calculator reveals:

| Tier | Price | What it fixes |
|---|---|---|
| [Rate Reality Kit](products/rate-reality-kit/) | $19 | This project's pricing — rate-setting, proposals, client screening, scope creep |
| [Systemization Pack](products/systemization-pack/) | $79 | Next month's income — retainers, onboarding, niche positioning |
| [Income Stability System](products/income-stability-system/) | $297 | The whole year — full pricing transition, pipeline, retainer portfolio |

## How this works

- [`DEMAND-ALCHEMY.md`](DEMAND-ALCHEMY.md) — the repeatable method: mine real demand signals, build the smallest sellable asset first, stack offers instead of picking one price, and a reusable AI-prompt workflow for running this same process in a new niche.
- [`EXECUTION.md`](EXECUTION.md) — the actual launch checklist: Stripe setup, fulfillment, free hosting via GitHub Pages, zero-budget distribution channels, and the revenue math behind the pricing (a model, not a guarantee).

## Status

Tier 1 (Rate Reality Kit) is fully written and ready to sell. Tiers 2 and 3 ship incrementally as Tier 1 sales validate real demand — see the "build status" notes in each product folder.
